# Getting help

- **How do I…?** Start with the [README](README.md), the [documentation index](docs/README.md) and the
  [runbooks](docs/runbooks/README.md).
- **Something is broken.** Search the [existing issues](https://github.com/arav7781/TREADOPS/issues) first, then
  open a bug report from the template, with the commit SHA and logs (remove secrets first).
- **Idea or request.** Open a feature request issue.
- **Security problem.** Don't open an issue; follow [SECURITY.md](SECURITY.md).

TreadOps is an independent prototype maintained on a best-effort basis; there is no guaranteed response time.
